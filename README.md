## ⚡ Installation

### One-Click Run (Auto-Installs Everything)

**Windows:**
```batch
git clone https://github.com/ayushrajdev9-cmyk/a2tools.git
cd a2tools
run.bat
```

**Linux / Termux:**
```bash
git clone https://github.com/ayushrajdev9-cmyk/a2tools.git
cd a2tools
chmod +x run.sh
./run.sh
```

### Manual Installation

```bash
git clone https://github.com/ayushrajdev9-cmyk/a2tools.git
cd a2tools
pip install -r requirements.txt
python A2Tool.py
```

> **Note:** The tool automatically installs all dependencies on first run!

## 🎯 Usage

1. Run the tool using one of the methods above
2. Select a category by entering the number (1-20)
3. Select a specific tool from the sub-menu
